# Security policy

The current unreleased 0.1.x source is the supported development line. Older snapshots
have no separate security maintenance; update to the latest reviewed source.

Report vulnerabilities privately through [GitHub private reporting](https://github.com/Berkayr/bw-esp32-flasher/security/advisories/new)
(Security → Report a vulnerability). Do not disclose an exploit in a public issue.
If private reporting is unavailable, do not publish sensitive details; wait for the
maintainer to enable that channel. This policy does not enable GitHub settings.

Include the affected revision, setup A–E, impact and safe reproduction steps.
Remove serial numbers, Wi-Fi passwords and other personal data from all logs.
Do not test a vulnerability by flashing or interrupting someone else's hardware.
Reports will be reviewed by the maintainer; no response deadline is guaranteed.
