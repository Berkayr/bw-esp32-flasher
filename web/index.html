ESP32 scooter flasher

Computer · USB · keep power connected

Web Serial is not supported here. Use Chrome or Edge on a computer with HTTPS (or localhost), or use the phone Wi-Fi mode after installing the board.

Install once, then connect your ESP32.

1. Install the ESP32 (once)

Use a classic ESP32-WROOM-32 with exactly 4 MiB flash, a USB data cable and Chrome/Edge on a computer. C3/S2/S3 and other flash sizes are not supported by this image.

Disconnect the controller wires during installation. Installation replaces the ESP32 software and files. Choose erase when prompted. This installs the flasher on the ESP32; it does not flash the scooter.

Installer requires desktop Chrome/Edge.

Maintainer: build and publish the installer image before sharing this page.

If no USB port appears, try a data cable and the USB chip vendor's driver: CP210x (Silicon Labs) or CH340 (WCH, Windows). On Linux, ensure your user has serial-port permission.

2. Connect over USB

After installation, close the installer dialog to release its serial port. Connect below and select the same USB port. An installed board can skip step 1.

Connecting interrupts the phone web server and turns Wi-Fi off for clean scooter communication. Do not connect while any flash is running. Disconnect releases USB; press ESP32 RESET afterwards to restore phone Wi-Fi mode.

3. Wire the controller

Disconnect the dashboard. With USB connected, switch the scooter on and connect verified ground first.

Wire probe wizard

Use when the connection check fails. It changes GPIO modes and may switch the scooter off. It cannot prove an unknown wire is safe.

  1. Measure voltages first. Leave out red, supply and battery-voltage wires.
  2. Connect ESP32 GND to verified ground, then unknown safe wires to your chosen GPIOs.
  3. Enter 1–6 distinct GPIO numbers and run the probe.
Allowed: 4, 5, 13, 14, 16–19, 21–23, 25–27, 32, 33.

Data/status frames → ESC TX → ESP32 RX. Held high → possible ESC RX, but could be a supply: verify first. Held low → possible ground or driven-low line. Floating → RX or keep-alive; if the scooter switches off, investigate keep-alive. Activity without Brightway frames is inconclusive, especially for LEQI.

After probing, restore the normal wiring above and run Check connection again. Keep-alive is restored high when the probe ends.

Flashing takes about 4 minutes on the tested Xiaomi 5. Packet N/N still requires finalization. Wait for the final success message. If USB disconnects, keep power on and wait at least 10 minutes before reconnecting: the board may continue flashing. Never reset a running flash.
